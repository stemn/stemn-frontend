# Stemn Desktop changelog

Release notes of each version, newest first. `scripts/release/prepare.mjs` adds the entry of a new
version (from the titles of the pull requests merged since the previous `desktop-v*` tag); edit it
before tagging. The entry of the version being built becomes the update feed's `releaseNotes` and the
in-app release notes. See RELEASING.md.

## 0.0.26 (2017-07-30)

- Last release of the original Stemn Desktop (Electron 1.x).
