# CAD fixtures

`assembly.step` is a byte-identical copy of `services/api/src/core/__tests__/samples/cad/assembly.step` in
stemn-backend: a two-part assembly (`base-plate` and `bracket`) generated by that directory's `generate-samples.py`.
The backend converter tests and the API render tests (both CAD providers) use the same file, so the website e2e
test renders the same input. Copy it again when the backend samples are regenerated; do not edit it.
