# PCB fixtures

Byte-identical copies of stemn-backend's shared PCB samples (`services/api/src/core/__tests__/samples/pcb`, generated by that
directory's `generate-samples.py`). The backend's PCB converter tests, the API's render and diff tests and these website e2e tests
use the same files. Copy them again when the backend samples are regenerated; do not edit them.

- `blinky-v1.kicad_pcb` → `blinky-v2.kicad_pcb`: two revisions of a small KiCad board with one change of each class (test point
  TP1 added, C2 removed, R2 swapped from 0603 to 0805: modified, R1 turned 90 degrees: moved, the rest unchanged), for
  `specs/pcb.spec.ts`
- `blinky-v1.kicad_sch`: the board's schematic, for the preview test
- `samples.json`: what each sample converts to, and the entity ids of each class between the revisions
