# Simulation fixtures

Byte-identical copies of stemn-backend's shared simulation samples (`services/api/src/core/__tests__/samples/simulation`,
generated by that directory's `generate-samples.py`, where `samples.json` lists what each should convert and diff to). Copy
them again when the backend samples are regenerated; do not edit them.

- `manifold-v1.vtk` → `manifold-v2.vtk`: a VTK legacy multiblock case in two revisions, for `specs/simulation.spec.ts`:
  `probe` added, `baffle` removed, `body` meshed again (modified), `outlet` moved 0.5 along z with its pressure `p` lower
  by 1, `inlet` and `wall` unchanged; on the inlet `p` changes by -0.25 to +0.5 and the velocity `U` by 0 to 0.5
- `inlet.vtu`: one block of the case as a VTK XML unstructured grid, for the single-file preview
