# CAD fixtures

Byte-identical copies of stemn-backend's shared CAD samples (`services/api/src/core/__tests__/samples/cad`, generated by
that directory's `generate-samples.py`). The backend converter tests, the API render and diff tests (both CAD providers)
and these website e2e tests use the same files, so the e2e tests render the same input. Copy them again when the
backend samples are regenerated; do not edit them.

- `assembly.step`: a two-part assembly (`base-plate` and `bracket`), for `specs/cad.spec.ts`
- `bracket-assembly-v1.step` → `bracket-assembly-v2.step`: two revisions of a five-part assembly with one change of
  each class (washer added, pin removed, base plate and bracket modified, spacer moved, nut unchanged), for
  `specs/diff.spec.ts`
